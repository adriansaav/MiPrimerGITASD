Para el manejo de ramas
git branch es para crear una rama
La rama master es por defecto, y esta es un estandar viejo de Github
La rama main es la principal del proyecto que desde hace 10 años se estandarizó
El comando para entrar a una rama:
git checkout nombredelarama

El comando git remote add origin https://github.com/adriansaav/MiPrimerGITASD.git lo que hace es enlazar es enlazar el repositorio local con el repositorio remoto

El comando git commit -m "aqui va una descripcion de los cambios que se hicieron"
sirve para tomar una fotografia de todo lo que hemos hecho

git commit -m "Mi primer archivo en repositorio"
